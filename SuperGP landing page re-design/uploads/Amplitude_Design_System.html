Amplitude Design System

A replicable design system documenting the visual language observed on amplitude.com: monochrome-first UI with a single blue accent, pill-shaped controls, generous whitespace, and gradient/dark sections used sparingly for emphasis.

Visual hierarchy

Design principles

Five patterns explain almost every screen on the site.

PrincipleHow it shows up
Monochrome-firstBody copy, buttons, borders and the wordmark all run in pure black/white/gray. Color is rationed, which makes the palette feel premium rather than playful.
One accent, used deliberatelyA single blue (#1E61F0) carries links, data-viz lines and interactive highlights. It never competes with black for attention.
Gradient as a special-occasion deviceThe blue→purple→pink gradient appears only as thin transition strips between sections and inside one hero illustration — never as a background wash.
Type does the heavy liftingHeadlines are oversized, bold, tight-tracking display type (60px+, -1px letter-spacing). There's little decoration — the wordmark itself becomes a full-bleed graphic in the footer.
Whitespace signals confidenceSections run 60–110px of vertical padding with no clutter; product screenshots float in isolation rather than being tiled densely.

Imagery

Product mockups & illustration

Two image modes: (1) real product-UI screenshots in a dark navy "device" frame with the blue accent driving all data-viz; (2) abstract 3D gradient ribbon renders reserved for premium CTA moments. No stock photography, no human imagery on the homepage.

Layout patterns

Section templates

The homepage is built from ~6 repeating templates. Reuse these instead of inventing new layouts.

TemplateStructure
HeroCentered kicker pill → bold H1 → gray lede → two pill CTAs. No image, pure type.
Feature splitTwo columns: heading + copy + mini feature cards on one side, a floating product screenshot (rounded, soft shadow, often tilted) on the other. Alternates left/right down the page.
Logo / integration gridTabbed toggle (e.g. MCP / SDK / CLI) above a 4-column grid of plain icon cards.
Gradient dividerA ~60–120px full-width strip in the brand gradient, used purely as a transition beat between light sections.
Dark CTA bannerRounded navy panel, abstract gradient render on one side, bold white headline + single pill CTA on the other.
Footer wordmarkStandard link footer, then the full brand name set at ~140px as a graphic, black background — the logotype becomes the closing visual.
